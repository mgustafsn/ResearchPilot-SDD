# ResearchPilot-SDD (Course project SWCON)

ResearchPilot-SDD is a local, single-user tool for managing research projects,
searching OpenAlex for scholarly papers, ranking results by local embedding
similarity, and saving references. The project is being rebuilt in reviewed
feature slices; see [the approved scope](docs/scope.md) for boundaries and status.

## Repository and project report

Use this Git repository to track the complete project, including source, project
documentation, and reviewed changes. Keep discussions and issues with the project
record where the course repository supports them. Each member should make their
own contributions so the commit history shows who did what. The submitted project
report should describe the work distribution and link it to those contributions.
